# 大肥鱼房间

一个 3D 房间，她在里面按**时间 + 聊天状态**做不同的事。

## 状态

| 条件 | 状态 |
|---|---|
| 0–8 点 | 睡觉 |
| 8–19 点 | 电脑前 |
| 19–24 点 | 床上刷手机 |
| 你刚发消息 | 立刻拿手机 |
| 25 分钟没说话 | 回到按时段的默认 |

## 页面

3D 房间（浅色大理石、奶油沙发、深木橱柜、晨光窗）+
主体角色 + 左下角对话流 + 右上角心情条。

## 换成自己的模型

把 `.glb` 或 `.vrm` 放到 `pages/room/model/character.glb`，
页面会自动加载并挑 `idle / sleep / work / phone` 四类动画；
没有模型就用内置的卡通形象。

## 命令

`/房间` 查看当前状态。

## 行为：她会自己走过去

房间现在有锚点寻路，不再只是换姿势：

| 命令 | 她会做什么 |
|---|---|
| `/房间 看电视 60` | 从当前位置走到沙发 → 坐下 → 电视屏幕亮起 |
| `/房间 撸猫 60` | 蹲到猫窝边，三只猫在旁边打转 |
| `/房间 梳妆 30` | 走到梳妆台，抬手臂整理 |
| `/房间 拉伸 30` | 在地毯上坐着伸展 |
| `/房间 看书 60` | 窝在沙发上看书 |
| `/房间 去沙发 30` | 走过去坐下，不开电视 |
| `/房间 刷抖音 30` | 走回床上躺下 |
| `/房间 结束` | 回到默认状态 |

实现方式：`ANCHOR` 里定义每个位置的坐标、朝向和姿势，`goTo()` 走直线过去
（带走路摆臂动画），到位后切姿势并切换镜头。没有 navmesh，房间是矩形所以够用。

**已知限制**：现在的人物和家具都是代码拼的几何体，坐下会有穿模；
换成骨骼模型 + 建模房间后这个现象会消失（阶段 2/3）。

## 她的一天

工作日要上班，周末在家，不用你叫她，她按时间自己过。

**周一到周五**

| 时段 | 在哪 | 做什么 |
|---|---|---|
| 0:00–6:50 | 床上 | 睡着 |
| 6:50–7:40 | 窗边 | 起床洗漱 |
| 7:40–8:25 | 电脑前 | 吃早饭 |
| **8:25–18:30** | **不在房间** | **在公司上班** |
| 18:30–19:35 | 猫窝边 | 下班回来先撸猫 |
| 19:35–22:00 | 沙发 | 看电视 |
| 22:00–23:00 | 梳妆台 | 洗漱收拾 |
| 23:00–24:00 | 床上 | 刷手机 |

**周六周日**

| 时段 | 在哪 | 做什么 |
|---|---|---|
| 0:00–8:30 | 床上 | 睡到自然醒 |
| 8:30–10:00 | 窗边 | 起床发呆 |
| 10:00–12:00 | 电脑前 | 在电脑前 |
| 12:00–14:00 | 沙发 | 吃午饭 |
| 14:00–17:00 | 地毯 | 拉伸看书 |
| 17:00–19:00 | 猫窝边 | 撸猫 |
| 19:00–22:00 | 沙发 | 看电视 |
| 22:00–23:30 | 梳妆台 | 收拾 |
| 23:30–24:00 | 床上 | 刷手机 |

**上班时房间是空的**（她真的不在），只剩猫。刚聊完天 25 分钟内，无论在哪她都会先拿手机回你。

## 三只猫

豆豆（银渐层）、妞妞（布偶）、点点（橘猫），各有猫窝、床尾、地毯、窗边几个落点，
睡着 → 醒来走两步 → 换个地方睡，尾巴会摆，头会转。

## 常见问题

**页面一直停在「正在搭建她的房间」，黑屏**

三个东西缺一个就会卡住（浏览器控制台会有 404）：

```
pages/room/three/build/three.module.js
pages/room/three/examples/jsm/utils/BufferGeometryUtils.js
pages/room/three/examples/jsm/utils/SkeletonUtils.js
```

前两个是 three 主库，后两个是 `GLTFLoader.js` 依赖的工具模块（three r187 起 requirement）。
缺 `BufferGeometryUtils` / `SkeletonUtils` 时页面不会报错，只是永远不结束加载。

**画面里没有人，只有房间**

正常会回退到内置卡通形象；如果连卡通形象都没有，看控制台是否有 WebGL 报错。
