# 大肥鱼健康监控

她挂了不会自己说，这个插件替她说。

## 查什么

| 项 | 判定 |
|---|---|
| 心智库 | 文件在不在、能不能打开、记忆条数是不是 0 |
| 状态文件 | `hormones.json` / `persona_core.json` / `memory.db` 是否缺失或太久没更新 |
| 磁盘 | 剩余空间低于阈值（默认 5%） |
| 插件目录 | 三个核心插件目录是否还在 |

## 怎么告警

- **连续两次**自检失败才告警（避免瞬时抖动）
- 通过 AstrBot 主动消息推到你指定的会话
- 恢复后不打扰，只在下次出事时再发

## 命令

| 命令 | 作用 |
|---|---|
| `/健康` | 立刻体检，返回结果 |
| `/健康 测试` | 发一条测试告警，验证链路 |
| `/健康配置` | 把当前会话设为告警接收方 |

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `interval_seconds` | 1800 | 自检间隔 |
| `notify_umo` | 空 | 告警接收会话，用命令自动填 |
| `disk_min_pct` | 5 | 磁盘告警阈值 |

## 注意

它不检查"她还在不在回消息"——因为半夜没人聊天是正常的，那样会误报。
只查**硬错误**：库坏了、文件没了、盘满了。
