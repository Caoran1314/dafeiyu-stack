# 大肥鱼3D记忆脑

把她的记忆画成一颗**真实皮层脑**（MRI 模型），外加一条从出生到今天的时间线。

## 页面

- 中央：皮层脑，点节点看连线与相关记忆
- 左：活跃/归档数量、节点类型图例、四激素进度条
- 右：标准（人格锚点）/ 回溯 / 评估 / 技术
- 底部：暂停流动 / 转动视角 / 重置视角 / 显示隐藏

## 时间线

按年份排开她的一生（2004 → 现在），点开看当时的配图与"当时在聊什么"。
数据来自旧库 episodes + 新库 memories，自动去重、自动挂图。

## 依赖数据

- `brain.db`（脑图）
- `dafeiyu_brain/memory.db`（时间线的真实日期）
- AstrBot 主库（聊天图片）

## 命令

`/脑3d` 手动刷新。

## 注意

直链 token 7 天过期，建议从「面板 → 插件」进入。
