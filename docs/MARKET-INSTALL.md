# 在官方市场安装

10 个插件已提交 AstrBot 官方市场。装法比自定义源更省事：**直接搜插件名**。

## 搜什么

| 搜索关键词（复制即可） | 得到 |
|---|---|
| `大肥鱼心智内核` | 记忆衰减 + 向量召回 + 技能 SM2 + 生命卡 |
| `大肥鱼心境` | 四激素心境引擎 |
| `大肥鱼人格内核` | 人格向量钳位 |
| `大肥鱼拟人管线` | 去 AI 腔 / 一句一行 / 错字 |
| `大肥鱼记忆大脑` | 本地 SQLite 记忆（旧库） |
| `大肥鱼3D记忆脑` | 3D 皮层脑 + 时间线 |
| `大肥鱼相册` | 话题命中时发照片 |
| `大肥鱼房间` | 3D 房间 |
| `大肥鱼音色` | GPT-SoVITS 克隆音色 |
| `大肥鱼拟人度评测` | 只看不改的拟人度指标 |

也可以直接搜作者：`Caoran1314`

## 装哪几个

| 想达到的效果 | 装这些 |
|---|---|
| **只想让她记住事** | 大肥鱼心智内核 |
| **想让她有情绪** | + 大肥鱼心境 |
| **想让她性格稳定** | + 大肥鱼人格内核 |
| **想让她说话像人** | + 大肥鱼拟人管线 |
| **全套（推荐）** | 上面 4 个 |
| 想要 3D 页面 | + 大肥鱼3D记忆脑 / 大肥鱼房间 |
| 想要语音 | + 大肥鱼音色（需自建 GPT-SoVITS） |

## 装完要做的

1. **重启 AstrBot**（面板 → 系统 → 重启，或 `docker compose restart astrbot`）
2. 到面板 → 插件，确认启用
3. 三个心智插件一起启用时：

```
dafeiyu_hormone        inject = false
dafeiyu_persona_core   inject = false
dafeiyu_mindcore       inject_mode = primary
```

4. 在 QQ 里发 `/心智状态` 验证

## 装完界面上会多出什么

| 条目 | 来自 |
|---|---|
| 大肥鱼3D记忆脑 | `dafeiyu_brain3d` |
| 大肥鱼房间 | `dafeiyu_room` |
| 记忆大脑 | `dafeiyu_brain` |

没装对应插件就不会出现。页面直链 7 天过期，从侧边栏重新进即可。

## 和自定义源的区别

| | 官方市场 | 自定义源 |
|---|---|---|
| 怎么装 | 搜名字 | 加源地址 |
| 更新 | 市场推送 | 重装 zip |
| 收录 | 需审核 | 即时 |

两个可以同时用，不冲突。**建议用官方市场**，省事。
