# 常见问题

## 部署

**容器起不来 / 一直 Restarting**

```bash
docker compose logs --tail=100 astrbot
docker compose logs --tail=100 napcat
```

常见原因：`.env` 里 `DATA_ROOT` 路径没权限；`NAPCAT_UID/GID` 不对；端口被占。

**扫码后 QQ 一直掉线**
小号风控。换网络、隔几小时再扫；新号前两三天最容易掉。

**端口冲突**
改 `.env` 左边三个端口：`ASTRBOT_WEBUI_PORT` / `NAPCAT_WEBUI_PORT` / `ASR_PORT`。

## 人格

**她动不动说“我不能……”“作为 AI……”**
1. `safety_mode` 还是 true → 改成 false
2. 人格里写了否定句（“你无法发语音”）→ 删掉，改成正面表述

**她说话像客服**
确认 `dafeiyu_human` 已启用（它负责去 AI 腔、一句一行）。

**她记不住昨天的事**
发 `/心智找 关键词` 看权重。可能：
- 记忆提取还没触发（`batch_size` 默认 4，聊够 4 句才提）
- 权重被衰减到底（琐事正常，重要的事不该）

## 记忆

**记忆不增长**
`/心智` 看总数。`inject_mode` 设成 `off` 时不会召回，但提取仍在跑。

**记忆变少了**
只有权重低于 0.02 且超过 365 天才下沉到归档，不会物理删除。`/心智` 能看到各池数量。

**心智库能不能删**
可以，删了 `memory_core.db` 会重新从旧库导入种子，但权重和技能会重置。

## 情绪

**她一直很凶**
`/心境` 看皮质醇。如果一直高，说明负面事件太多。可以 `/心境重置` 强制回基线。

**情绪没反应**
确认 `dafeiyu_hormone` 启用；`inject` 关掉是对的（由 mindcore 统一装配）。

## 语音

**语音发不出来**

```bash
docker compose logs --tail=50 sovits
```

- SoVITS 服务没起
- 参考音频路径不对
- `ref.wav` 太短或太吵

**语音不像**
参考音频是关键：8–10 秒、安静环境、正常语速、不要带 BGM。

## 3D 页面

**打不开 / 提示 token 无效**
直链 7 天过期。从「面板 → 插件 → 大肥鱼3D记忆脑」重新进入。

**页面一片空白**
`Ctrl+F5` 强刷。还不行看浏览器控制台报错。

**房间里她是内置那个卡通形象**
说明没放模型。把 `.glb/.vrm` 放到 `pages/room/model/character.glb` 就会优先用你的模型。

## 安全

**会不会泄漏聊天记录**
全部数据在你自己机器上，容器只连你配置的模型 API。仓库里没有任何真实数据。

**要不要开公网**
不建议。真要开，至少给 16185 加反向代理和 Basic Auth，NapCat 的 16099 不要暴露。
