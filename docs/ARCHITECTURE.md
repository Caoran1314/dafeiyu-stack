## 二、四层

### 入口层
QQ 客户端 ↔ NapCat（OneBot v11 协议端）↔ AstrBot。
只负责收发，不做任何判断。

### 表达层（AstrBot 插件）
**怎么说话**：

| 插件 | 管什么 |
|---|---|
| `dafeiyu_human` | 去 AI 腔、一句一行、错字、延迟 |
| `dafeiyu_voice` | 把文字换成克隆音色 |
| `dafeiyu_photo` | 话题命中时发真实照片 |
| `meme_manager` | 表情包 |
| `proactive_chat` | 主动找你 |
| `dafeiyu_brain3d` / `dafeiyu_room` | 可视化页面 |

### 心智层（三个引擎 + 一个入口）
**怎么想**：

| 插件 | 职责 | 状态文件 |
|---|---|---|
| `dafeiyu_persona_core` | 六维人格 + 单轮钳位 + 内核校验 | `persona_core.json` |
| `dafeiyu_hormone` | 四激素 + 阻尼回归 + 事件扰动 | `hormones.json` |
| `dafeiyu_mindcore` | 记忆权重/衰减/晋升/向量召回 + 技能 SM2 + 离线补偿 + 装配 | `memory_core.db` |

**唯一注入点**是 `mindcore` 的 `on_llm_request`：它一次拼好
`人格 + 心境 + 记忆 + 技能`，再写进系统提示。另外两个插件只更新状态（`inject=false`）。

### 数据层
三库两文件一卡，见下表。

## 三、数据归属

| 数据 | 路径 | 读写 | 谁在用 |
|---|---|---|---|
| 旧记忆库 | `dafeiyu_brain/memory.db` | 只读 | 心智内核当种子导入 |
| 脑图库 | `astrbot_plugin_memory_brain/brain.db` | 只读 | 3D 脑 / 时间线 |
| 心智库 | `dafeiyu_mindcore/memory_core.db` | 读写 | 记忆召回、技能、权重 |
| 心境 | `dafeiyu_hormone/hormones.json` | 读写 | 语气、语音情绪、发图意愿 |
| 人格 | `dafeiyu_persona_core/persona_core.json` | 读写 | 语气底色 |
| 生命卡 | `dafeiyu_mindcore/*.lifecard` | 导出/导入 | 整包搬迁 |

**旧库永不回写**：心智内核用 `file:...?mode=ro` 打开，物理上写不进去。

## 四、核心算法

### 1. 人格钳位

```
P_new = P + clamp(dP, -0.12, +0.12)     每轮每维最多变 0.12
‖P_core‖ ≥ 0.15                          内核强度保底
```

`P_core` 带 sha256 签名，文件被改会自动退回默认内核。

### 2. 四激素

```
h(t+dt) = h_base + (h(t) - h_base) · exp(-LAM · dt)      LAM = 0.02/小时
```

半衰期 34.7 小时。事件扰动：正向/负面/治愈三类，各维系数不同；
负面事件对催产素的打击会乘 `(1 - 依恋惯性)`，避免一次吵架清零。

派生三个量：

- `f_endo`：记忆召回加权（催产素高更愿提旧事，皮质醇高压抑）
- `Qmax`：压力大时技能发挥上限
- `bonus`：陪伴类技能依恋加成

### 3. 记忆衰减与晋升

```
短期：half = 7 天      中期：45 天      长期：180 天
w(t+dt) = w(t) · exp(-ln2/half · dt)

海马分 = 0.40·情绪 + 0.20·实体丰富度 + 0.25·回想次数 + 0.15·依恋
≥0.35 → 中期       ≥0.60 且回想≥2 → 长期
长期 w<0.02 且 age>365天 → 归档 → 深层 → 痕迹
```

半衰期可配置，默认偏温和（不是照抄论文里的激进参数）。

### 4. 召回打分

```
base        = (0.45·sim + 0.30·cover + 0.15·w_n + 0.10·rec) · (0.5 + salience)
score_final = base · f_endo
```

`sim` 用 `bge-m3` 余弦（无向量时退回字面二元组），
`w_n` 是权重归一，`rec` 是新鲜度。

### 5. 技能 SM2

```
LAM_EFF = LAM_B · (1/max(I,1))^0.3
L(t+dt) = L(t) · exp(-LAM_EFF · dt)
EF_new  = clamp(EF + (0.1 - (5-Q)(0.08 + (5-Q)0.02)), 1.3, 2.5)
L_new   = min(1.0, L + 0.25·(Q/5)·(1-L)/(1+0.05·I))
```

间隔 `I` 参与衰减：越熟练越抗遗忘。
Q 分来自「用户下一句反馈 + 她自己对回复的自评」，再受 `Qmax` 压制。

### 6. 离线补偿

```
dt_raw < 7 天   : dt_eff = dt_raw
7 ≤ dt_raw < 30 : dt_eff = 7 + (dt_raw-7)·0.5
dt_raw ≥ 30     : dt_eff = 7 + 23·0.5 + (dt_raw-30)·0.15
封顶 90 天
```

用 `dt_eff` 批量跑记忆衰减、技能衰减、激素回归。

## 五、一次请求的时序

```
1. on_llm_request（mindcore, priority 60000）
   ├─ 结算上一轮技能 Q
   ├─ 取 query 向量（bge-m3）
   ├─ 召回记忆（向量 × 权重 × f_endo）
   ├─ 读 hormone / persona 状态
   └─ 拼成一段 ≤ 预算字符的上下文，写进 system_prompt

2. 模型生成

3. on_decorating_result（human, priority 90000）
   ├─ 去 AI 腔、一句一行
   └─ 截断超长

4. on_decorating_result（voice / photo / hormone 闸门）
   ├─ 语音：按激素选情绪，合成并替换文本
   ├─ 照片：命中话题且心情允许时附图
   └─ 主动消息：心情差则清空 chain

5. 后台 tick（每 15 分钟）
   ├─ 记忆衰减 + 回想结算
   ├─ 技能衰减
   └─ 池晋升 / 下沉
```

## 六、为什么这么设计

| 选择 | 原因 |
|---|---|
| 旧库只读 | 出问题能立刻回退，历史数据永不丢 |
| 三个插件分开 | 分别调参、分别回退，不用改一处全动 |
| 单一注入点 | 避免提示词里堆三段互相打架的内容 |
| 参数可配 | 默认值偏温和，激进派可以自己调快 |
| 生命卡 | 换机器不用重养 |
